webserv demo

A static site served by webserv (conf/default.conf).

Static files

  • A second page
  • Directory listing (autoindex)
  • A route mapped to another directory (alias, with its own index file)
  • A redirected URL (301)
  • An incorrect URL (custom 404 page)

Uploads

  • Upload files, then see them in /upload/

CGI

  • GET with a query
  • POST a form
  • Meta-variables
  • Reads a file by relative path
  • A script with an error (502)
  • An infinite loop (504 after 10 s)
  • Cookies and a session (bonus)
  • PHP (bonus: a second CGI)
